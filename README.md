# 오늘도 근무 중 이상 무! — All Clear Today!

카를스반 영지 성문의 신입 경비병이 되어 방문객의 서류와 물품을 심사하는 검문 시뮬레이션 프로토타입입니다.

## 현재 구현
- 1~5일차 규칙 확장
- 통행증 / 신분·물품 신고서 비교
- 인장 감정 / 소지품 수색 / 재질문
- 통과 / 거부 / 경비대 호출 판정
- 오판 경고 및 2회째부터 벌금
- 일일 임금과 생활비 차감
- 위조 인장 / 만료 서류 / 마물 위장 / 밀수품 NPC
- PC / 모바일 반응형 UI
- 외부 이미지 없이 index.html 단독 실행
